## Why each fix matters

- **robots.txt and sitemap.xml did not exist.** The catch-all rewrite (`"**" -> /index.html`) served the home page with HTTP 200 for both, so crawlers got HTML instead of a robots file and sitemap. The same rewrite turned every mistyped URL into a 200 copy of the home page (a "soft 404"), which search engines penalize. This is a static site with no client-side routing, so the rewrite is not needed. Do not re-add it.

- **Structured data ties the brand names together.** The brand is **StemDeck44**; "StemDeck" is a search alias. Keep both in `alternateName`, and keep the App Store URL in `sameAs` and `downloadUrl`.

- **The bottom "Get StemDeck on the Mac App Store" button went nowhere.** That was lost downloads, not just a search issue.

## Branding and naming (user decisions)

- The brand is **StemDeck44**, deliberately: the user has other products with the "44" suffix. Do not rename the product to plain "StemDeck" on the site or in the App Store.

- The App Store listing is named "StemDeck44" (subtitle "Live stem playback for stage"). Apple's search already returns it first for "stemdeck", "stemdeck44" and "stem deck", so no store rename is needed.

- An unrelated open-source desktop app also called **StemDeck** exists (github.com/stemdeckapp/stemdeck: local stem separation plus mixer, alpha, actively released). It is what web search shows for "StemDeck" today. Don't copy its wording or imply any affiliation.

- The publisher is **Dipko Services LLC**.
